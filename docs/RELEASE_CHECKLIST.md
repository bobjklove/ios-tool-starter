# 上架清单

以下均为待办检查项。勾选前须取得对应证据；文档中的步骤不代表已完成后台配置、设备验收或审核提交。

## 工程与构建

- [ ] 替换 App 名称、图标、文案、主 target 与两个测试 target 的标识、bundle ID、支持网址和隐私政策网址。
- [ ] 如改名工程文件，同步重命名 `ToolStarter.xctestplan`，更新 `project.yml` 中 `testPlans.path`，并检查 `tools/sync-test-plan.py` 对工程名、App target 和测试 target 的假设。
- [ ] 如改名本地 `.storekit` 配置，同时更新 `ToolStarter.xctestplan` 中 `defaultOptions.storeKitConfiguration` 的相对路径，以及工程中引用该配置的地方。
- [ ] 执行 `xcodegen generate`；确认 postGen 同步后的测试计划引用正确，并检查目标平台、签名和资源。
- [ ] 版本号和构建号正确；每次上传前递增构建号，并在项目验证记录中记下上传结果。

## 商店资料

- [ ] 用最终文案构建采集截图。使用虚构样例；检查 6.9 英寸 iPhone 和 13 英寸 iPad 的英语、简体中文与日语截图及画面内所有小字。
- [ ] 补齐三种语言的名称、描述、关键词、购买说明、隐私政策内容及截图；核对产品内文案与商店资料一致。
- [ ] 核实当前目标市场适用的备案、合规、年龄分级及隐私披露要求，按实际功能和内容填写；不要沿用旧项目结论。
- [ ] 隐私问卷按最终二进制、SDK、系统权限和数据流重新核对，见 [隐私申报参考](PRIVACY.md)。
- [ ] 在后台核实非消耗型商品 ID、商品类型、价格、销售地区和本地化，并确认首个内购与 App 首版一起送审。

## 验收与授权

- [ ] 默认单元与 StoreKit 计划通过；单独运行 UI 测试时记录目标设备、语言和 xcresult。默认计划只选择单元/StoreKit 测试，UI 测试 target 仅编译。
- [ ] 在真机完成导入、原尺寸 PDF、免费额度、购买成功、取消、恢复、后台隐私遮挡和系统分享等关键流程；尚未完成的场景明确标记未验收。
- [ ] TestFlight 沙盒账号购买和恢复流程有实际设备证据。现有 StoreKit 集成测试仅覆盖购买与退款撤销；`AppStore.sync()` 恢复及真机购买目前未验收。
- [ ] 对源码、文档和资源运行敏感扫描，并人工检查截图、商店元数据与二进制资源中的品牌、bundle/product、联系方式和凭据。
- [ ] Archive、上传、后台建商品、定价和提交审核由有权限的人在获得当次授权后执行。
