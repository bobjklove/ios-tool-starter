# 隐私申报参考

此说明反映当前模板源码，不能代替对最终构建、依赖 SDK、系统权限和数据流的复核。加入网络请求、账户、广告、分析或崩溃上报后，必须重新评估隐私问卷和隐私政策。

当前隐私清单声明未跟踪、无跟踪域名、未收集数据类型；同时申报使用 `UserDefaults`，理由码为 `CA92.1`。`CA92.1` 是隐私清单中的 API 使用理由码，不是存储键或购买配置。免费导出历史实际使用 `UserDefaults` 键 `free-export-history-v1`。

照片由 `PhotosPicker` 按用户选择读取；模板不请求整个照片图库访问权限。分享通过系统分享面板交由用户主动发起。分享接收方或第三方服务收到文件后如何处理由其决定，面向用户的隐私说明应覆盖这一点。

上架前由项目负责人按最终二进制、SDK、系统权限和实际数据流填写并确认隐私问卷；不要仅凭模板声明直接勾选。隐私政策和支持页面的目标网址、适用市场要求及内容也须逐项核实。
